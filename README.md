# Aiwason 智能光电母线系统官网

一个现代化、响应式的企业官网，仿照英伟达官网设计风格，专为Aiwason智能光电母线系统品牌打造。

## 🌟 特性

### 设计特色
- **现代化设计**: 采用深色主题和渐变色彩，营造科技感氛围
- **响应式布局**: 完美适配桌面、平板和移动设备
- **英伟达风格**: 借鉴英伟达官网的设计理念和视觉效果
- **双语支持**: 中英文无缝切换

### 技术亮点
- **纯前端实现**: 使用HTML5、CSS3和原生JavaScript
- **Tailwind CSS**: 采用实用优先的CSS框架
- **动画效果**: 丰富的CSS动画和JavaScript交互
- **性能优化**: 轻量级设计，快速加载

### 功能模块
- **导航栏**: 固定导航，平滑滚动定位
- **Hero区域**: 大屏幕展示，粒子背景效果
- **产品展示**: 三大产品系列介绍
- **技术展示**: 核心技术可视化展示
- **解决方案**: 行业解决方案介绍
- **关于我们**: 公司介绍和统计数据
- **页脚**: 完整的联系信息和链接

## 🎨 视觉设计

### 配色方案
- **主色调**: Aiwason Green (`#00D2AA`)

## 🎨 自定义配置

### 修改主题色彩
在`style.css`文件的`:root`选择器中修改CSS变量：
```css
:root {
    --aiwason-green: #00D2AA;  /* 主色调 */
    --aiwason-dark: #0A0A0A;   /* 深色背景 */
    --aiwason-gray: #1A1A1A;   /* 灰色背景 */
}
```

### 调整动画速度
修改CSS动画的`duration`属性或JavaScript中的时间参数。

### 更新内容
直接编辑`index.html`文件中的文本内容，支持中英文双语。
